## 内容与错误展示

- 卡片顺序为具体问题→影响/预期变化→具体改法→简短证据，能力说明默认折叠。Token仅T2工具返回、T3重复载荷、T4历史结果。
- N只用完整回放实际修改请求计数；只有观察/匹配计数时标“涉及”并说明未评估，不补0、不称已修改。各卡影响与收益不相加。
- L1–L3仅后端合格完整建议；精确>1个百分点保留，L4/L5不走收益门槛。没有合格L1–L3不能回退为成对发现卡。
- 业务页面不出现Plan/版本身份JSON、source_pointer/规则原对象或完整64k请求；摘要与身份留在内部接入校验/文档中。局部证据文本不解析后重序列化，不用substring第一次命中伪造高亮。
- 缺新扩展/旧历史报告：说明该报告未生成新版建议/局部证据，保持可选择的历史身份/时间，不在访问时重算。缺业务依据、读取失败、后端未检查与零收益分别展示，不都写“待业务确认”。
- 未完成检查只留必要提示，不恢复置信度/覆盖率指标、评估表单、授权参数、组合评估主流程。
