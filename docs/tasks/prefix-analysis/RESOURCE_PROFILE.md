# 诊断资源预算与本地校准

2026-10-31，资源限制不是业务异常阈值，也不改变严格>1pp门槛。HTTP提交必须显式传RuntimeOptions，未提供时不猜测规模或静默采样。版本diagnostics-runtime-1。

本地校准采用GLM-5.2固定资产、原监控8 CPU预算，完整源先由监控生成；诊断复用同CPU进程，不启动新编码池。测试test_diagnostic_resources.py，三档3 passed（52.63s），源构造耗时另存。以下为单次实际结果，不是华为现场吞吐或SLA：

原始可追溯记录：artifacts/validation/prefix-analysis/lh009/scale-{16,64,128}.json，含系统、Python、模型资产/编码身份、实际配置、覆盖及磁盘。RSS为同一pytest进程累计高水位，包含监控/Tokenizer资产，不是诊断增量或单请求占用；不据此声称线性扩容。

固定本地验证配置：前序候选2、小范围8、源请求128、源正文32MiB、单请求1MiB、单对比较1,000,000字节、深度64、Token单请求单位10000/候选1000、低命中发现256、自动实验1/组合0、任务编码1024、Plan 16MiB。它是可复现实验配置，不是自动套用的生产默认值。128条档在65条时耗尽低命中发现预算，如实partial；Token仍检查128条；达到门槛的full评估仍包含全部128条。不得把该partial描述成全量问题排查。

生产/更大appid必须显式给预算；源超限直接失败且无收益，不自动缩小appid窗口。小范围不足、候选截断、规则未查和评估未完成各自留理由；单项Plan、比较、编码预算独立检查。预算增加可能增加耗时/内存，当前只验证到上述规模，未声称150k全量现场校准。

实现边界：SQLite只保存候选索引，内存保留当前/有限前序请求与IDs；Plan逐请求编译并受16MiB默认上限约束，达到上限拒绝，不能截断评估F。pilot选择仅保留索引/时间元数据，不保留全appid正文。报告/原始证据GET进行摘要核验，不编码；大产物摘要核验会有I/O成本。worker重启保留私有孤儿文件便于审计，当前不自动清理，运维清理需另行授权。

边界验证：公共运行预算20项单元覆盖字节/计数/深度刚低于、等于、超过与中断；Token单位/候选/比较的插件内预算由Token TA006独立验收。未测容器、GPU推理、华为现场或前端。
