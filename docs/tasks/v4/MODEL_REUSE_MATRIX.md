## 四种不同判断

1. **资产可共享**：固定来源revision和实际文件SHA一致时，优先复用同一不可变文件/内容寻址对象，保留每个模型自身来源与别名映射。不无谓复制或重新下载；旧锁记录不覆盖。
2. **Tokenizer是否等价**：不仅tokenizer.json，还核special/added tokens、normalizer/pretokenizer、tokenizer_config、BOS/EOS/pad及运行库版本/模式。文本相同不代表模板输入相同。
3. **Template是否等价**：同名Jinja文件不够；核实际加载来源（也可能内嵌config）、默认参数、tools/tool_call_id、system/developer、多段content、thinking开关、generation prompt及协议差异。Tokenizer相同而Template不同，可只复用前者。
4. **既有结果是否可复用**：资产相同也不自动允许把旧模型真实观测/MA结果改名给新模型；新的服务规格、缓存块配置、思考模式、计量参数/真实cached数据可能不同。现有计算缓存的复用必须满足原有完整身份键及接口约束，不新增绕过校验的捷径。

## 证据与最小验证

先查项目env/encoding-assets.lock.json、models/README.md、已锁来源及现场实际服务配置；新官方资源需核官方仓库或厂商一手文档，不用第三方文章推断同一性。记录准确URL/revision/文件SHA/许可证；私有镜像资产由华为agent只读输出摘要，不上传权重或凭据。

待用户批准验证范围后，按真实适用协议构造少量代表输入：中文/英文、system+user、tool调用/结果、JSON/转义/Unicode、thinking模式等，分别比对渲染文本字节SHA、完整token ID序列或其SHA、数量、特殊Token位置。只测适用模式，不给不支持模式伪造默认。有限样本相同只能支持已测模式，不能证明所有输入等价；资产差异但样本相同不能直接判无条件复用。

旧资产与新资产逐项给“可复用且依据明确 / 仅指定模式可复用 / 不可复用 / 证据不足”。证据不足保留待核，不默认通过。若只有厂商明确兼容声明也需记录验证覆盖与限制，不能把声明和实测混写。

明确模型规格与MA模型制品（如32K/64K/128K）不同；相同CSV用新编码做离线对照，不得写成新模型线上运行结果。新chunk_seconds未给时标待配置；chunk_tokens用户既有默认8192也需标口径，不虚构新硬件性能。

## 实现优先级

优先最小model注册/别名与共享不可变资产映射；不为3个模型先重构插件框架。先证明能共享再修改锁/适配，必要差异只做局部处理。候选交接必须包含“实际共享什么、哪些不共享、旧结果怎样保持可读、验证了什么模式”四项。
