| 已安装适配器明确缺T3协议或T4替代依据 | no_feasible_plan并给业务缺项，完整检测可ready；不提示填前端表单 |

| typed basis仅有recipe名称而无真实来源 | 不作为授权；尤其不绕过T3真实引用/删除检查 |
