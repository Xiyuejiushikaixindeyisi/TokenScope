## 1. 完成度与不可混用的证据

- 必须完成：本机后端功能、真实HTTP/CLI端到端、进程/存储故障、旧V1/S0及已接入公共能力兼容、工程质量、资源使用记录、逐条设计符合性。
- 独立记录：正式前端联调/视觉验收；现场代表CSV的性能与源字段语义；生产发布/镜像交付。本轮禁止部署/打包，前端未启动或现场CSV不可用不能被虚构为通过。
- 本机后端closed可以与上述外部事项pending并存；总体产品“交付完成”不能在这些事项未完成时宣布。关键MA能力仅以stub验证不能完成后端验收，三模型实际编码资产/内核不可用时相关门槛保持pending。

## 3. 健壮性与工程门槛

| 类别 | 必需覆盖 |
| --- | --- |
| 输入 | 原始JSON/CSV多行、BOM、非法编码/引号、大单条、重复ID、非整数/超界、未知别名、缺表头、文件引用越界/符号链接越界、复制时文件变化 |
| 算术 | 总量精确整数（累计超过64位不丢精度）、比率零分母、负数不修正、两图各自样本守恒、12桶与小时守恒、Q筛选不改变缓存历史 |
| 模型/能力 | 缺资产、未知模型或hybrid不支持、DeepSeek未决模式、请求显式模式、已有设置不覆盖、运行中配置变更仅影响后续任务 |
| 存储/资源 | 磁盘不足、输入/结果只读权限、SQLite busy/提交失败、摘要损坏、进程退出、长请求下有界批处理、跨任务资源释放 |
| 并发/恢复 | 真实进程锁互斥、终态单向发布、幂等键冲突、同run只发布一次、seal恢复不改字节、旧任务恢复不看MA库 |
| API/兼容 | 旧S0原Schema/样例与实际旧接口回归，MA命名空间及三个UUID身份区分，错误不回显正文，目录revision/分页一致，GET只读 |
| 工程质量 | 固定环境pytest、ruff check、ruff format --check、mypy成功；不存在未解释的新skip/xfail；代码审查记录职责、异常、事务、类型/单位及资源关闭 |

没有人为固定总体覆盖率百分比；按风险和需求检验证据。测试可验证的失败不得仅写“现场再看”。文件级/配置/系统错误与行错误必须分开。

## 4. 资源与性能

报告两CSV总bytes、pre/now记录数及集合覆盖、UUID数、长输入分布、冻结配置、CPU预算、wall/阶段耗时、峰值RSS、磁盘占用及失败/恢复情况。至少有小型精确夹具和规模较大的合成资源场景，说明构造方式、哈希、重复程度与实际资产。

资源验收包括无无界请求/Token全量加载、UUID顺序执行、重复运行不持续泄漏句柄/内存、同state_root无双任务超配。为可复核的合成规模在M005 PLAN冻结输入与资源预算后再跑，不在看到失败后缩小数据冒充原目标通过。

未取得代表性MA CSV与用户性能目标时，只报告实测成本/资源和适用范围，不承诺每规格双文件<7200秒，也不拿高重复合成输入证明现场时效。现场资料只回传单份md内嵌脱敏关键证据；不索要绝密CSV。
