# TTFT性能校准：首版最小输入与后续验证

2026-10-31。用户已认可本方案，替代此前过宽的“最小数据清单”。当前状态保持**代码完成，性能校准待完成**；既有软件U000–U005已闭环，后端新口径适配已实现，契约2.0.0可提交最小情景；旧1.0.1含O的完整情景仍兼容。前端尚未接入验收。见[设计](DESIGN.md)与[调整审批稿](TTFT_MINIMAL_ADAPTATION_REVIEW.md)。

## 1. 必需输入

| 参数 | 来源与最小要求 | 缺少时影响 |
| --- | --- | --- |
| 模型/配置身份 | 选定common_name、model_id及简短部署/配置说明；说明τ对应哪套配置 | 无法确定参数用于哪个模型情景 |
| K | 整个batch总Token预算，明确正整数；8k须落实为8000或8192，不能混用 | 无法将计算时间换算为Token量 |
| τ | 对应配置下一个batch的计算耗时，正数秒；简要注明实测来源或人工假设 | 无法计算吞吐近似，不提供默认值 |
| W | 用户明确选定的首Token前全部非计算耗时预算，非负秒数 | 无法确定可计算时间；不得默认0 |
| T及比较符 | 正数秒目标，≤或<；比较符可明确采用默认≤ | 无法确定目标边界 |
| L=P90 | 当前appid×common_name有效请求的模板后输入长度最近秩P90，由已有CSV统计提供 | 无正P90时不显示具体比例 |

K已知、W作为选定超参数时，每模型主要新增的性能数值可以仅提供τ；T由用户输入，L由系统读取。简短配置身份和来源说明用于防止错用参数，不要求完整设备/版本盘点或逐step日志才能运行参考计算器。ID、revision及幂等键等由系统管理，不是新增现场采集门槛。

## 2. 获认可的简化假设与计时边界

- K是整批预算；首版**主动近似单个请求每计算K个Token耗时τ**。这不是已证实的整批预算与单请求实际进度等价。
- τ只指batch计算耗时。尾部不足K也按一整个chunk计费；C=0时计算耗时为0。
- **W覆盖目标TTFT边界内、首Token前计算之外的全部耗时**：首次等待、chunk间等待，以及未计入计算时间的缓存读取、调度、通信等耗时。不另行收集、展示或扣除固定开销O。
- 采用已有GF发出请求至首Token的模型处理口径；不把GF发出前的GB排队并入W。若未来测量端点不同，应明确另建情景，不混用。
- W可显式取5/10/20秒等人工情景；这些不是已测得的P90等待值，页面不能自动替用户选定。明确输入0可以，缺失不能当0。
- 若提供的batch时间实际包含非计算耗时，须先澄清边界，以免与W重复计入；不要求为此单独测O。

## 3. 公式与输出含义

令C为剩余需计算输入Token量：
`TTFT_ref(C)=W+ceil(C/K)×τ`，`B=T−W`。

- ≤目标：B<0无预算，否则n=floor(B/τ)。
- <目标：B≤0无预算，否则n=ceil(B/τ)−1。
- `Cmax=min(L,nK)`；`r_ref=(L−Cmax)/L`。保持精确数值计算，避免等号浮点误差。
- n=0可给100%理想化参考，并明确实际可行性未证实；不能保证完整块/MTP等约束下可达。
- nK≥L可给0%，仅表示当前假设下P90长度计算预算足够。
- 无预算、缺参、非法参数或无正P90不显示具体命中率；不要把无预算显示成100%。

算术示例（不是实测校准）：明确取K=8192、τ=1s、W=5s、L=32768。T≤8s时n=3，参考比例25%；T<8s时n=2，参考比例50%。不将示例保存成三模型默认参数。

结果名称：**P90长度请求所需参考前缀命中率**。它是给定固定K/τ/W下该长度所需的最低理想化前缀复用比例，不是整份CSV的ΣH/ΣP门槛，也不是生产P90 TTFT达标保证。现有聚合理想命中率不能与之直接比较并输出达标结论。

## 4. 仅用于进一步验证准确性的材料

| 后续材料 | 解决的问题 | 缺少时限制；不阻止人工参考计算 |
| --- | --- | --- |
| 设备、引擎/模型revision、P/D拓扑、思考模式及负载详情 | 界定跨配置可迁移性 | 只适用于所述情景，不外推其他配置 |
| 逐step耗时、实际batch Token及请求关联 | 检查整批预算近似单请求进度、固定τ误差 | 共享batch可能使估计偏乐观，不能称有效进度已校准 |
| 同口径逐请求输入、命中、TTFT及时间端点 | 检查端到端误差与真实命中分布 | 不能证明生产P90达标或所需总体命中门槛 |
| 等待与计算分解、并发和到达信息 | 检查W的代表性及负载相关性 | W保持人工超参数，不称实际等待分位数 |
| 重复实验、耗时分布、保留验证样本及证据摘要 | 估计误差、稳定性和适用范围 | 不报告已验证精度、置信范围或完整校准通过 |

上述材料不得重新包装成首版参考计算器的必填采集清单。已有材料可附加保存；没有证据不能伪填样本数、覆盖范围或摘要。缺少明确长度范围时标“适用范围未验证”，不伪造无限覆盖；用户主动提供范围时，超范围须明确处理。

## 5. 人工参考与真实性能验证分开

实测τ加人工W、整批进度近似，仍是**假设情景参考**。单独取得batch实测耗时不等于整套公式已获真实性能验证，不自动标verified_measurement。进一步验证应说明数据范围、误差及证据，再单独确认准确性结论。

局限包括共享batch的预算分配、上下文长度/混合负载导致的τ变化、W与请求长度/命中的相关性、尾chunk整块计费及真实缓存可达性。P90等待加P90计算不等于P90 TTFT。服务级流量投到某配置只是假设情景，不重现生产分流或实例回放。

展示必须保留输入快照、来源和版本。条件变化后旧结果失效；历史结果仅在其原条件下查看。必要参数未填全时不显示具体比例，人工参数不能冒称已校准。当前既有代码与新方案的差异、兼容及前端修改均按[审批稿](TTFT_MINIMAL_ADAPTATION_REVIEW.md)记录实施范围；后端见U006–U008，前端尚未实施。
