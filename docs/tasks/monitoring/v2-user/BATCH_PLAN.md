## 1. 每批必须维护的记录

正式执行时，在本目录batches/Uxxx下建立以下四份文件，不提前生成假的通过记录：

| 文件 | 必填内容 |
| --- | --- |
| PLAN.md | 设计版本/需求ID、前置RESULT、输入基线commit及脏文件、改动文件/类/接口、具体步骤、共享拥有方、验收条件、资源预算、回退方案 |
| ISSUES.md | issue ID、复现输入/步骤、影响与严重度、根因、修复/设计决定、关联测试、状态与残余风险；无问题时写“截至某验证点未发现”，不可预写无缺陷 |
| TESTS.md | 用例ID/目的、期望值独立来源、环境/资产/数据hash、命令、时间/退出码、实际结果、日志路径/摘要、失败及复测、未执行原因；区分mock/真实编码/真实服务/现场 |
| RESULT.md | closed/blocked/needs_revision、完成范围、源码commit或文件摘要、测试汇总、未决问题、设计差异、可消费产物/契约、回退验证、下批条件、memory更新位置 |

状态planned→active→verifying→closed；失败留active/blocked并说明原因，不倒填通过。批次未closed不进依赖批；等待外部事实时可做本批独立验证，不绕过门槛。每次实际进展和问题变化增量写memory/tasks/monitoring-v2-user.md，CURRENT只维护阶段链接；不覆盖其他session状态。

要求编号：U-R01时间/原文；R02别名/模式；R03用户范围/绑定；R04众数统计；R05筛选排行；R06TTFT模型/来源；R07不可变结果/恢复；R08跨线兼容/资源；R09内网参数；R10统一验收。编号前缀均为U-。

## 2. U000：基线、共享接口与契约固定

**开发方案（本批以协议和验证准备为主）**
1. 核实实际分支/HEAD、源码脏状态和V1发布身份；读取当前csv_reader、domain、pipeline、statistics、worker/API装配及S0，不依旧CODEMAP标题猜现状。
2. 固定用户控制存储、基础提交恢复、扩展目录格式；写用户独立Schema、设计OpenAPI、字段/状态/错误/幂等/分页定义及样例与SHA清单。设计OpenAPI标未实现，不能覆盖旧OpenAPI。
3. 登记公共文件和变更维护窗口：本线时间/别名/模式；MA负责共享worker/装配提案；交付配置归审查打包。形成可执行依赖表与可消费接口，不因职责表假定已跨会话通知。共享装配未定时本线router保持独立，先验证独立app。
4. 固定测试数据生成说明、三模型资产身份、资源预算和端到端基线。人工校准夹具与真实校准材料目录区分；无真实性能数据明确pending。
5. 给出新旧配置迁移/回退方案、请求绑定幂等恢复时序及侧索引原子发布点。

**问题记录重点**：S0严格DTO是否冲突、公共改动重叠、MA时区默认泄漏、common_name/model_id混同、模型资产不就绪、任务额度归属未定。

**测试门槛**：U000-T01链接/Schema/样例全部通过；T02正反例覆盖所有状态及精确数值；T03审查幂等崩溃时序与唯一维护方；T04所选既有回归基线通过，失败必须归因并解决相关阻断。预算写明数值和测量方法后才开始性能验收，不能事后定门槛。

**闭环**：契约/共享签名冻结记录、可复用样例、准确未决表；仅受外部依赖影响的真实MA/校准测试可pending并限定后续声称。接口未固定不能进入实现。

## 3. U001：V1兼容修复与访问参数

**代码方案**：修改公共csv_reader日期识别/UTC wrapper、domain初始别名/DeepSeek配置，保持旧revision和原文；新增明确配置差异/迁移路径，不自动覆盖数据库。为MA提供显式源时区的解析能力，签名遵U000。交付配置只交接绑定参数需求，可本地静态校验示例，不启动容器或改运行配置。

**问题记录重点**：DD/MM歧义、纳秒丢失、跨日offset、DeepSeek显式选项冲突、旧default仍未决、别名冲突、监听与容器端口混淆。

**测试及门槛**
- U001-T01 ISO与DD/MM同一UTC时刻归一结果一致；闰日、跨日、1–9位亚秒、非法值、溢出边界确定；旧签名调用结果不变。
- T02 MA提交显式source_timezone=UTC时无offset正确归一；不支持的时区声明/窗口冲突拒绝；错误字段准确，不将约定冒充导出已核实。
- T03三模型现场别名逐个正确识别、未知/冲突拒绝；已注册自定义配置不覆盖，revision CAS冲突可恢复。
- T04DeepSeek新默认/显式true/false/旧default路径及资产ready状态准确；原JSON摘要和J不因选择默认被改写。
- T05真实编码小样本（可用资产）与V1对照，非受影响结果一致；无资产不能用mock宣称通过。
- T06内网参数示例、健康检查loopback保持；未进行网络开放或远端可达测试。
所有必要回归通过才closed，交付现场验证pending不阻断纯兼容代码关闭。

**闭环交付**：公共函数/配置变更版本、迁移差异和测试摘要供MA消费，列明部署无变化。

## 4. U002：用户绑定、扩展存储与众数索引

**代码方案**：新user_monitoring模块实现UserRunService/BindingStore与ProjectionBuilder；复用原基础run、只读facts。控制库记录意图和派生submission_key，独立结果身份及恢复；流式精确累加C稀疏箱；由维护任务回填旧结果，封存后发布，不改旧seal。

**问题记录重点**：提交双写中断、不同服务别名误合并、重复hash_id去重、无限长度造成密集分箱、SQLite SUM溢出、并列峰信息丢失、残留tmp误发布。

**测试及门槛**
- U002-T01两个appid相同前缀隔离、不同common_name/任务缓存独立；同任务duplicate保留。
- T02绑定不符拒绝；文件可选common_name冲突不静默拆分；同key重试仅一个基础run；各中断点恢复无孤立重复任务。
- T03 C={100,200,6100}、w=5000→首箱count=2、sum=300、mean=150、share=2/3；C={100,6100}保留两个众数，排序代表100。
- T04 0/4999/5000/199999/200000/极大C边界；空集、全部不同、重复长度、双峰/长尾，所有箱count=N、sum=ΣC；宽度变化不改P90/总量。累加跨64位仍准确。
- T05同源同版本索引可复算；原seal、facts、S0输出hash不变；无facts返回reanalysis_required，未就绪不返回空榜假装ready。
- T06构建与rename/发布之间中断、磁盘不足、源摘要变化、重复构建竞争：无半成品可读，恢复或清晰失败。
小规模独立算例全等；真实facts集成通过；资源增长符合U000预算。

**闭环**：扩展格式与恢复证据、旧数据升级/回退记录。删除派生索引后可重建，源结果不可删除。

## 5. U003：搜索排行服务与只读接口

**代码方案**：RankingService读取ready索引，精确范围/比率/均值比较；全局过滤排序后分页；独立router对接U000契约。服务/API层共享逻辑，拒绝MA身份；查询不构建索引。众数明细用分页避免并列峰无界响应。

**问题记录重点**：NULL排序、字符串大小写/通配符、float近似导致乱序、先分页后排序、错误revision复用、同值页面重复/遗漏。

**测试门槛**
- U003-T01四指标升降序、组合上下界、appid中文/大小写/%/_、空结果，和独立穷举oracle全等。
- T02并列值UTF-8稳定次序、每页拼接等于全榜且无漏重；limit上界/offset末尾/非法参数/NaN拒绝；缺值末尾且不满足数值范围。
- T03精确分数均值排序和边界过滤、大整数>2^53、revision冲突；换bin_width的指标与身份一致。
- T04真实HTTP对Schema/样例校验，未完成/缺索引/MA任务拒绝；观察GET无文件写入/任务入队/编码调用。
- T05在U000预算内验证代表性组数的排序/分页，不能以限制真实输入长度修性能。
所有代码路径、字段/错误行为与契约一致，旧S0受影响回归通过。

**闭环**：可供前端消费的真实API对照样例、版本摘要及查询性能记录；不冒称前端已接入。

## 6. U004：TTFT情景与参考计算器

**代码方案**：实现ScenarioStore不可变revision、Estimator确定公式及状态；校验模型/长度/部署范围、秒单位及参数来源。POST显式评估保存输入/结果，GET只读；无逐请求模拟/等待拟合。人工假设和校准数据严格区分，输出不含总体命中率达标判断。

**问题记录重点**：ceil/floor错用、lt/le等号误差、O重复计入、K与缓存block混用、缺τ仍给数、反算100%误称可行、混合规格伪装生产校准。

**测试门槛**
- U004-T01设计示例le→50%、lt→75%；整数边界用精确十进制计算；目标放宽r不增，等待/开销增加r不降（同有效域）。
- T02T≤0、W/O负数、τ/K非法、NaN/Inf、空组/P90=0、W+O不满足目标、n=0、nK≥P90，状态和值符合契约。
- T03模型不符/过期或缺来源/覆盖范围外明确拒绝或不可用；人工假设有醒目标识；无τ不给数；原聚合理想值高于r也不产出达标结论。
- T04情景revision变化不改旧估算，幂等重试返回同一结果、异体冲突；不调用正文/编码/回放；真实HTTP样例通过Schema。
- T05独立公式oracle覆盖阶梯边界；真实校准如取得，另做保留样本误差/条件覆盖验证；没有则标未执行，软件功能与实测准确性分别结论。
软件门槛通过可closed，性能实证pending必须保留到最终报告，不伪称已校准。

**闭环**：公式、参数单位/来源、样例、可复现结果与误差证据或缺失事实。
