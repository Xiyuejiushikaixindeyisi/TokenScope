# HV2-R1-USER计划与门槛
2026-11-03；只改本线，候选2.1.0待独立冻结；不监听服务、不提交push、不打包。
1. R1-U1：只读目录、发布隔离、明确历史顺序、快照分页/模型appid来源。门槛：多模型/多历史/空/未发布、分页与GET零写入。
2. R1-U2：独立版本默认库与用户提供种子、显式CAS/幂等。门槛：精确别名、持久重启/null停用、不跨模型默认、旧快照不变。
3. R1-U3：自动解析范围/P90/默认，复用精确公式。门槛：缺τ/W、W0/T=W、严格与小数、K覆盖恢复、不缩放τ、并发幂等。
4. R1-U4：候选Schema/运行OpenAPI/样例、严格过滤审计及本线/S0回归。门槛：无监听回归、静态/类型、来源与分析公共层一致、SHA交接；现场数差和精度证据不足如实留项。
每步问题、实际测试和闭环分别见ISSUES/TESTS/RESULT。总设计师独立验收与冻结之后才由前端接入；本线不代签。
