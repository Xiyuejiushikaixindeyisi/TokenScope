# TokenScope 第一期目标输入与已确认约束

依据：用户于 2026-10-23 提供目标想法，并批准据此组织工作区。用户随后明确：第一版目标尚未完成讨论和规划，应先划分任务，由各任务 session 分别与用户调研、讨论、设计和实现。

本文保存目标输入、明确暂缓项和工程约束，不是已经收敛的功能规格或实施计划。文件路径暂保留 V1_SCOPE.md，以维持既有链接。功能设计、开发 batch、测试与回退方案在对应任务中形成；打包前需用户同意等已明确要求继续有效。

## 产品定位

TokenScope 以 MaaS 为中心，向上解释业务如何消耗 Token，向下解释这些 Token 如何消耗算力，并把发现的问题转化为可验证的优化行动，覆盖业务方优化与 MaaS 方优化。

部门面向 To B 租户提供 MaaS，以 appid 区分业务，为选定模型提供约定并发，不限制 Token 总量，按模型与长度承诺 P90 TTFT、P90 TPOT。

一期首先对业务负责，重点观察负载本身的变化：理想命中率下降、调用过程膨胀、上下文组成变化。其中依赖 session/turn/trace 的调用过程深入分析暂缓。

## 形态与边界

- 最终后端通过 Docker Compose 一键启动。
- 所有功能先在项目本地环境实现并测试；打包前必须取得用户同意，不反复构建 Docker 或镜像来替代本地开发。
- 环境组织参考 MemScope，目标使用 H100；驱动、Docker 等具体版本后续核实。
- 向华为机交付镜像、代码、执行 prompt。
- 一期可以由用户手动采集数据并放到机器上。
- 展示可采用本机可访问的网址，并参考 PrefixLens 已有展示能力；不要求首先打通完整前端、后端和数据库链路。
- 用户进一步明确前端采用 HTML 展示已有成果，可参考 kvcache-blog；页面读取不触发新的计算或分析，具体交互方式由展示任务设计。
- 数据采集、Token 监控、问题分析、自进化相互解耦；监控发现问题后才启动对应分析。

## 周期窗口

| 时段 | 采集或触发间隔 | 每次数据覆盖时长 | 用途 |
| --- | --- | --- | --- |
| 白天，流量较大 | 2 小时 | 2 小时 | 形成该窗口的 Token 监控 |
| 夜晚，流量较小或离线任务较多 | 4 小时 | 2 小时 | 形成所采集窗口的 Token 监控 |

日夜分界、窗口对齐、时区、补传和未覆盖时段的处理方式尚未确定。夜间配置不能解释为已分析全天连续数据。本轮未创建定时任务。

## 基线与监控粒度

主键为 appid × 模型版本。先关注请求量、长度分布与缓存复用。

| 监控内容 | 汇总 | 单条请求分布 |
| --- | --- | --- |
| JSON 的 Token 数量 | 需要 | 需要 |
| Chat Template 之后的 Token 数量 | 需要 | 需要 |
| 实际需要重新计算的 Token 数量 | 需要 | 需要 |
| 理想命中率 | 需要 | 本期未要求 |

JSON 统计范围、序列化口径、实际重新计算量的来源及理想命中率的统计条件，后续在 contracts 中定义。数据缺失时不能把理想未命中量直接标为实际重新计算量。

计算归属已明确：统一 Token 编码、计量及理想命中率计算由 Token 监控任务维护。可以复用 PrefixLens 现有计算实现；原因分析消费监控的信息或复用同一实现，不维护第二套独立计算口径。

## 问题分析

### 理想命中率异常

复用 PrefixLens 分析动态内容、system prompt 等造成的前缀复用问题，保留原因与典型请求证据。

### 单条请求长度异常

当模板后长度分布剧烈变化时，检查模板控制文本、完整工具 Schema、历史消息、工具返回和重复序列化的贡献。

### 调用过程分析暂缓

请求量与模板后总 Token 同时激增时，未来可能分析 session 数量、session 的 turns 深度、每个 turn 的模型调用数量，以及缺少进展的 Loop、过多 subagent 等行为。

目前 session、turn、trace 相关数据能否采集尚待与同事确认；一期不把这些字段作为必需输入，不把这类深入分析作为当前交付承诺。

## 自进化 Agent

同时存在“问题报警”和“归因不足警报”时，唤醒 Agent 并通知运维人员。Agent 对该 appid × 模型版本的原始数据和已有分析结果开展启发式调查，解释原因并产出对应候选探测器，再通知运维人员验收。

候选探测器与已验收探测器分开保存。参考 SupervisorAgent 的使用方式及具体通知、调查、验证流程后续设计，本轮未接入或发送通知。
