# 候选参考项目

这是用户提出的候选清单。本轮不查询远端、不锁定版本、不将这些项目全部列为运行依赖。

| 候选 | 拟放置路径 | 后续需要确认的内容 |
| --- | --- | --- |
| PrefixLens 本机基础版 | upstream/prefixlens-local | 本机版本、输入输出与可复用接口 |
| PrefixLens 华为完整版本 | upstream/prefixlens-huawei | 现场来源、完整能力、与基础版差异 |
| deepseek-recipe | upstream/deepseek-recipe | 模型渲染、编码与适配边界 |
| TraceLab | upstream/tracelab | 用户所指项目的准确来源及相关能力 |
| kvcache-blog | upstream/kvcache-blog | 本地来源与可借鉴内容 |
| SupervisorAgent | upstream/supervisoragent | Agent 触发与监督机制的适用性 |
| OpenTelemetry GenAI | upstream/otel-genai | 语义约定来源与版本 |
| OpenInference | upstream/openinference | 数据与调用观测的适配范围 |
| Langfuse | upstream/langfuse | 可参考的观测与展示实现 |
| Polars | upstream/polars | 批量处理与性能适用范围 |
| Evidently | upstream/evidently | 基线与分布变化检测的适用性 |

表中路径为规划，尚未创建各仓库或引入源码。准确 URL、commit、许可证、快照摘要及实际用途在引入时核实；不根据名称猜测 TraceLab 等项目的仓库。
