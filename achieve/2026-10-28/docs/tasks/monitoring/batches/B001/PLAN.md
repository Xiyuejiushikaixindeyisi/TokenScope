# B001 开发方案

授权：2026-10-27 用户批准 v1.0 并进入开发。只在项目内创建源码/环境与测试。

1. 使用现有 uv 建项目 `.venv`（CPython 3.11），建立 pyproject/锁文件、类型与格式检查；记录实际版本，不替换系统 Python。
2. 定义不可变模型设置（GLM/Qwen/V4 默认 128/1536/32）、能力、请求引用、质量/状态及运行快照；设置乐观 revision 校验，任务开始时读取最新设置并冻结。
3. SQLite 保存模型设置 revision、排队/运行状态和快照；每次运行独立数据库保存输入记录/行错误，重复 hash_id 记录提示但保留。不可恢复错误不能转为坏行。
4. CSV 读取正确处理 UTF-8/BOM、引号/换行、长字段，保存完整 JSON 原串；UTC 纳秒精度排序，不猜数字时间戳单位；字段/纯文本消息/工具结构校验，无效行跳过。
5. `file_ref` 限输入根目录相对路径，解析及打开时拒绝越界/符号链接逃逸；输入复制、摘要及阶段计时计入运行。原始数据与配置分离。
6. 建共用服务层及 CLI/HTTP 的设置、提交、状态、健康/版本入口；完整分析依赖未完成时明确未就绪，不能输出伪统计。正式 OpenAPI/JSON Schema 从同一类型导出，登记后续结果接口。

## 本批门槛

- 默认值、非法 B/CP/模式、revision 冲突、下一运行生效/历史快照不变、增强通道拒绝。
- UTC 亚秒/offset/无后缀、BOM/换行/大字段、坏行与坏文件、重复记录、JSON 原文不改写、模型别名/冲突、超出输入根目录及符号链接用例。
- SQLite 状态转换/故障隔离，CLI 与 HTTP 同服务层，无计量能力时报告未就绪。
- pytest、ruff、mypy 对本批模块通过；schema/契约逐项核对，代码审查并闭环问题。记录实际命令和失败/复测。

## 回退

仅移除/回退本批 manifest 中的自有文件和隔离测试数据；不动原始 CSV、前端文件、上游快照。正式配置库迁移记录 schema_version，未知更高版本拒绝打开；环境可按锁文件重建。无全局 reset。
