# 运行与交付产物

- runs：监控与问题分析结果，关联数据窗口、配置和实现身份。
- agent_runs：自进化 Agent 调查、候选探测器及验证产物。
- builds：后续构建中间产物。
- releases：用户同意打包后按版本冻结的华为交付物。

每次正式交付包含镜像、代码和执行 prompt，并附版本清单、校验摘要和验证记录。当前没有发布版本，目录创建不代表获得打包同意。

Agent 候选探测器不能直接作为正式规则；验收记录与推广后的实现需要相互链接。研发协作记忆放 memory，不放在产品调查结果中。

运行产物默认不进入 Git，必要的证据索引由阶段文档或 evidence/manifests 保存。
